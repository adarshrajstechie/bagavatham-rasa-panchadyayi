# Rasa Panchadyayi — Next.js reader

A responsive, server-rendered reading experience for the supplied Malayalam Rasa Panchadyayi text.

## Stack

- Next.js App Router + TypeScript
- React 19
- `@/*` import alias mapped to `src/*`
- Server-rendered manuscript content for crawlability
- Google Translate website widget for visitor-selected translations
- No paid API, database, authentication, or runtime backend

## Run locally

Requires Node.js 20.9+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

Create a production build:

```bash
npm run build
npm run start
```

## Deploy to Vercel

1. Push this folder to a Git repository.
2. Import the repository in Vercel.
3. Use the default Next.js framework settings.
4. Add `NEXT_PUBLIC_SITE_URL` with your real production URL, for example `https://your-domain.vercel.app`.
5. Deploy.

No paid services or environment secrets are required. Vercel's free Hobby tier is subject to its current usage limits and terms.

## Translation behavior — important

The Malayalam manuscript is rendered on the server and remains the canonical source. The language selector invokes Google's free website translation widget for supported languages; no paid translation API key is used.

- Translations are machine-generated by Google at visitor request, not human-reviewed.
- The availability and language coverage of the third-party widget are controlled by Google and may change. Some less widely supported Indian languages may not be available through the widget even though they appear in the language menu.
- The translated page is not a separately authored/indexable language edition. Search engines receive the original Malayalam content.
- Selecting Malayalam reloads the canonical source if the widget cannot restore it.
- The app does not store or overwrite the original manuscript.

For publication-grade translations, use reviewed translation files per language and render each language as its own server-rendered route. This project intentionally does not fabricate translations or silently replace sacred source text with unverified wording.

## Source text integrity

The supplied file is included at:

`src/content/rasa-panchadyayi.txt`

It is copied from the uploaded TXT source without editorial correction, cleanup, truncation, or translation. The full source is loaded by the server component and displayed as pre-wrapped text.

## SEO and performance notes

Included:
- Server-rendered article text
- Metadata, canonical URL, Open Graph and Twitter metadata
- Article JSON-LD structured data
- `robots.txt` and `sitemap.xml` routes
- Responsive layout and readable Malayalam typography
- No heavy UI framework or animation library
- Reduced-motion support and no scroll locking
- Compressed production responses

Before launch, set `NEXT_PUBLIC_SITE_URL` to the canonical domain and verify the deployed site with Google Search Console, Lighthouse, and GTmetrix. No implementation can guarantee an A grade or search ranking across every network, device, and third-party dependency. Google Fonts and Google Translate load externally and can affect lab scores.
